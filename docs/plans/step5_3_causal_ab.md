## 1. 목적

STEP 5-2·5-2b는 같은 이미지라도 N이 마지막 자리일 때만 False-Yes가 낮다는 것을 보였다.
이 실험은 그 차이가 **어디를 거쳐** 답에 반영되는지를 개입으로 확인한다.

| 실험 | 묻는 것 | 개입 |
| --- | --- | --- |
| A | 마지막 입력 토큰의 residual(h_q)이 그 이미지 묶음에 고유한, 답을 바꾸는 정보를 갖는가 | 같은 묶음의 두 순서(N-first 오답 ↔ N-last 정답) 사이에서 층 ℓ의 h_q를 이식 |
| B | 답이 이미지 뒤 텍스트 토큰(질문 + 마지막 토큰) → N 이미지 토큰 attention에 의존하는가 | 4층 구간 하나에서 그 attention을 차단 또는 강화하고, 같은 입력의 P 이미지 한 장에 같은 개입을 한 것과 비교 |

해석 범위
- 5-2·5-2b 이미지와 기준 출력을 다시 쓴다. **새 이미지에 대한 독립 검증이 아니다.**
- B는 N 위치를 정답으로 아는 오라클 개입이다. 실제로 쓸 수 있는 교정법(게이트)은 이후 단계에서 다룬다.

## 3. 실험 A: 질문 토큰 patching

### 3.1 짝과 방향

| 방향 | 받는 쪽 | 같은 묶음 donor | 목표 답 |
| --- | --- | --- | --- |
| 복원 (A-H1) | N-first False-Yes | 같은 쌍의 N-last Correct-No | No |
| 오염 (A-H2) | N-last Correct-No | 같은 쌍의 N-first False-Yes | Yes |

**대조 donor C1 (다른 묶음, 조건 일치)**
- 조건: 같은 절반에 있는 다른 N 이미지의 입력으로, 다음이 모두 같아야 한다.
  - 클래스와 장수 (그래야 프롬프트가 같다)
  - 위치와 기준 답 (같은 묶음 donor와 같게)
- 후보가 여럿이면 전체 입력 토큰 수가 가장 가까운 것을 고르고, 그래도 같으면 seed 53으로 뽑는다.
- 받는 쪽마다 한 개를 실행 전에 정해 둔다.
- 후보가 없는 받는 쪽은 그 방향의 주 대비에서 빼고, 몇 개인지 보고한다. 모의 분할에서 현재 정의는 절반당 복원 0, 오염 1~3개였다.

### 3.2 개입

- 위치: 마지막 입력 토큰(답을 예측하는 토큰)에서 디코더 층 ℓ의 출력 residual
- 방법: 그 값을 donor의 같은 위치 값으로 바꾼다. 나머지 위치와 층은 그대로 두고, 바뀐 상태에서 greedy 생성을 이어 간다.
- 층: ℓ = 1~36 전체를 훑는다. ℓ = 0과 ℓ = 36은 점검용으로도 쓴다.
  - ℓ = 0: 마지막 토큰이 모든 입력에서 같아서, 이식해도 아무것도 바뀌지 않아야 한다.
  - ℓ = 36: donor의 답과 margin이 그대로 나와야 한다.

### 3.3 층 선택 규칙 (확정: 방향별)

1. 선택 절반의 받는 쪽만 쓴다. C1 donor가 있는 입력에 한한다.
2. 각 층 ℓ마다 S(ℓ)을 센다.
   - S(ℓ) = (같은 묶음 donor로 목표 답이 나온 수) − (C1 donor로 목표 답이 나온 수)
   - 정수로 세므로 동률 판단이 정확하다.
3. ℓ*_복원 = S_복원(ℓ)이 가장 큰 층, ℓ*_오염 = S_오염(ℓ)이 가장 큰 층이다. 동률이면 가장 이른 층을 고른다.
4. 후보는 ℓ = 1~35다. ℓ = 36에서는 두 donor 모두 자기 답을 그대로 내므로, 차이가 설계상 0이다.
5. 최대 S가 0 이하여도 같은 규칙으로 정하고 확증 판정을 그대로 진행한다.
6. 평가 코드가 자동으로 고른다. 확증 절반의 결과를 읽기 전에 해시와 함께 파일로 기록한다.

**기술 통계로만 보고 (판정과 무관)**
- 단일 층 ℓ*_합 = argmax [S_복원(ℓ) + S_오염(ℓ)] (같은 규칙, 동률이면 가장 이른 층). 선택 절반에서 고른 값과, 그 층에서의 확증 절반 결과를 보고한다.
- 같은 묶음 donor의 복원 답 변화율이 50% 이상이 되는 가장 이른 층. 절반별로 보고하고, 없으면 "없음"으로 적는다. 비교용으로 C1 donor의 같은 값도 함께 보고한다.
- 두 절반, 두 방향, 두 donor의 층별 답 변화율 곡선과 S(ℓ)/n 곡선. 확증 절반에서 ℓ* 이외 층은 탐색적이다.

### 3.4 주 가설 (확증 절반, ℓ*)

| 가설 | 추정량 | 방향 | 최소 의미 효과 |
| --- | --- | --- | --- |
| A-H1 복원 특이성 | 받는 쪽 평균 [성공(같은 묶음) − 성공(C1)], ℓ*_복원 | + | 0.15 |
| A-H2 오염 특이성 | 같은 정의, 오염 방향, ℓ*_오염 | + | 0.15 |

- 성공 = 이식 후 파싱한 답이 목표 답일 때다. unparsed는 실패로 센다.
- 단위마다 같은 가중치를 준다. 장수 3·4·5를 합쳐서 계산한다.

보조 결과 (판정 없음)
- ℓ*에서의 Δmargin 대비. Δmargin = 이식 후 margin − 같은 경로의 무개입 margin이며, margin은 fp32 변형이다.
- 장수별 결과
- All-P 부작용: A 단위와 같은 계열·장수에서 5-2 All-P의 두 순서끼리 이식한다. 지표는 기준이 Yes였던 받는 쪽 중 No로 바뀐 비율이다.
- 민감도 분석: 무개입 답이 기준과 다른 입력을 뺀 결과, 부호 불일치 입력을 뺀 결과

해석 단서
- 같은 묶음 donor는 받는 쪽과 이미지 순서가 다르다. 그래서 묶음 고유 정보와 순서 정보가 분리되지 않는다.
- C1 donor는 전체 토큰 수가 다르다(가장 가까운 것을 고름). donor 값은 받는 쪽의 위치에 넣는다.

### 3.5 쌍 확대 (보완 7, v3에서 채택)

**확대안**
- 복원의 받는 쪽: 5-2b의 가운데 위치 False-Yes까지 넓힌다.
  - 같은 계열·장수의 N-last가 Correct-No인 경우에 한한다.
  - 같은 묶음 donor는 그 N-last다.
- 오염 방향: 같은 (N-last 받는 쪽, False-Yes donor) 쌍을 그대로 쓴다.
  - 받는 쪽 N-last 590개가 donor 1~4개와 짝을 이룬다.
  - C1은 donor와 같은 위치 a의 False-Yes에서 고른다.

| | 현재 (N-first만) | 확대 (N-first + 가운데) |
| --- | --- | --- |
| 쌍 수 (전체) | 390 | 1,186 (첫 위치 390 + 가운데 796) |
| 장수별 | 159 / 128 / 103 | 351 / 404 / 431 |
| N 이미지 수 | 237 | 313 |
| N 이미지당 쌍 (가중 평균) | 2.0 | 5.4 |
| 절반당 쌍 (모의) | 193~197 | 588~598 |
| 절반당 C1 없음 (모의) | 복원 0, 오염 1~3 | 복원 2~7, 오염 5~7 |
| 예상 97.5% CI 반폭: 같은 N 이미지 안 상관 ρ = 0.3 (중앙 시나리오) | 0.10~0.13 | 0.08~0.10 |
| 예상 97.5% CI 반폭: ρ = 0 (쌍 독립) | 0.09~0.11 | 0.05~0.06 |
| 예상 97.5% CI 반폭: ρ = 1 (N 이미지 안 완전 상관) | 0.13~0.16 | 0.12~0.15 |
| GPU 시간 (A 전체) | 0.5~0.75시간 | 0.9~1.25시간 |

- 반폭 계산: 짝 차이의 분산을 0.30~0.48로 가정하고, 설계 효과 1 + (m − 1)ρ를 적용했다. m은 N 이미지당 쌍 수의 가중 평균이다.
- **이득:** 쌍은 3배로 늘지만 같은 N 이미지에 몰린다(가중 평균 5.4). 그래서 반폭은 ρ에 따라 6~43% 줄어든다.
  - ρ가 클수록 이득이 작다. 완전 상관이면 0.16 → 0.15 정도다.
  - 최소 효과 0.15와 비교하면, 확대해도 "의미 있는 효과 없음" 판정은 ρ가 작을 때만 가능하다.
- **대가**
  - 추정 대상이 "N-first → N-last 복원"에서 "끝이 아닌 위치 → N-last 복원"으로 바뀐다. 가운데가 2/3를 차지하고, 5장 비중이 커진다.
    - 5-2b에서 가운데와 첫 위치의 False-Yes 차이는 결론 유보(+0.04)였다.
    - 그래도 위치별 결과는 따로 보고해야 한다.
  - 오염 방향에서 같은 받는 쪽이 여러 donor와 짝을 이룬다.
  - C1 없음이 늘어난다.
  - 분할 균형 점수의 A 항목도 확대 정의로 바꿔야 한다.
- **채택하는 경우 사전 등록 변경 사항**
  - A 단위 정의
  - 위치별(첫·가운데) 보조 보고
  - 분할 점수
  - C1 조건 (위치 a 일치)

## 4. 실험 B: attention 개입

### 4.1 개입 (주 개입 위치 변경, 보완 4)

- **주 query:** 마지막 이미지 구간 뒤의 모든 입력 토큰이다. 즉 마지막 이미지의 vision_end 표시 다음부터 마지막 입력 토큰까지다.
  - 질문 텍스트와 채팅 템플릿 토큰이 들어가며, 입력마다 26~28개다.
  - 16개 head 전부에 적용한다. 생성되는 토큰은 바꾸지 않는다.
- **부가 query:** 마지막 입력 토큰만 (v1의 주 개입)
- 대상 토큰: 이미지의 image pad 토큰 구간(manifest의 `image_spans`)이다. vision start/end 표시 토큰은 넣지 않는다.
- 층 구간: 4층씩 9개 (1–4, 5–8, …, 33–36)
- 방법
  - 차단: 대상 attention logit을 −∞로 둔다. 대상 가중치는 0이 되고 나머지가 다시 정규화된다.
  - 강화: softmax 전에 대상 logit에 +log 4를 더한다.
- 대상
  - N 이미지
  - 대조군 P 이미지: 같은 입력에서 이미지 토큰 수가 N과 가장 가까운 것. 같으면 N과 위치가 가까운 것, 그래도 같으면 앞쪽 것을 고른다.

### 4.2 모집단 (5-2b 3~5장 전체 위치 격자, 기준 답으로 고정)

- 차단 (B-H1): Correct-No 입력
- 강화 (B-H2): False-Yes 입력

### 4.3 결과 변수

- 입력마다 계산한다.
  - Δm(대상) = 개입 margin − 같은 경로의 무개입 margin이며, margin은 fp32 변형이다.
  - C = Δm(N) − Δm(P)

### 4.4 구간 선택 규칙

- 주 query 조건에서, 선택 절반에서 가설별로 고른다.
  - 차단: 평균 C가 가장 큰 구간
  - 강화: 평균 C가 가장 작은(가장 음수인) 구간
- 동률(차이 1e-9 이하)이면 가장 이른 구간을 고른다.
- 확증 결과를 읽기 전에 기록한다.
- 부가 query 조건은 같은 규칙으로 따로 고르고, 기술 통계로 보고한다.

### 4.5 주 가설 (확증 절반, 주 query 조건, 선택된 구간)

| 가설 | 조건 ① 대비 C | 조건 ② N 대상 Δm(N) | 최소 의미 효과 (C) |
| --- | --- | --- | --- |
| B-H1 필요성 (차단, Correct-No) | 평균 C ≥ +0.5, 97.5% CI 하한 > 0 | 평균 Δm(N) > 0, 97.5% CI 하한 > 0 | +0.5 logit |
| B-H2 교정 (강화, False-Yes) | 평균 C ≤ −0.5, 97.5% CI 상한 < 0 | 평균 Δm(N) < 0, 97.5% CI 상한 < 0 | −0.5 logit |

- **지지 = ①과 ②를 모두 충족**할 때다. 둘 다 충족해야 하므로 다중 비교 보정을 추가하지 않는다(intersection-union 원리).
- **P 대상 Δm(P):** 추정값과 97.5% CI를 부호와 함께 항상 보고한다(판정 없음). C가 N 쪽에서 왔는지 P 쪽에서 왔는지 보여 준다.
- 입력마다 같은 가중치를 준다. 장수와 위치를 합쳐서 계산한다.
- 0.5의 근거
  - 5-2b H1b의 margin 효과 +0.36보다 크고, 5-2 N-last의 P 누적 margin 효과 +0.87보다 작다.
  - bf16 margin 단위(0.125)로 4칸이다.

### 4.6 보조 결과 (판정 없음)

- 부가 query 조건(마지막 토큰만)의 C, Δm(N), Δm(P), 그리고 주 query 조건과의 차이
- 답 변화율. 강화로 False-Yes가 No로 바뀐 비율은 오라클 교정률이다.
- 장수별, N 위치별(첫·가운데·끝), 구간별 곡선
- bf16 margin
- 부호 불일치 입력을 뺀 결과
- All-P 부작용: 5-2 All-P 3~5장 중 기준이 Yes인 입력, 주 query 조건을 쓴다.
  - N 자리 이미지와 대조 P에 차단·강화를 한다.
  - 지표는 Yes가 No로 바뀐 비율이며, 5%를 넘으면 경고로 표시한다.

### 4.7 해석 단서

- 질문 구간에서 N으로 가는 **직접** attention만 바꾼다.
  - N 뒤에 오는 이미지 토큰은 이미 N을 참조했을 수 있다. 그 토큰을 거치는 간접 경로는 남는다.
  - 간접 경로의 양은 N 위치에 따라 다르다. N-last는 간접 경로가 없다. 위치별 결과를 비교할 때 이 차이를 함께 적는다.
- **v1과의 관계:** v1에서 별도 후보로 뺐던 "질문 텍스트 구간 attention 개입"은 v2의 주 개입 위치(질문 구간 + 마지막 토큰)에 흡수되었다.
  - 질문 구간만 개입하고 마지막 토큰은 빼는 조건은 넣지 않았다.

## 5. 공통 규칙

**정밀도와 환경**
- 기준선과 같게 둔다: 언어 모델 bf16, 비전 bf16, sdpa.
- run.json에 GPU·드라이버·라이브러리 버전을 기록한다.

**계산 방식 (빠른 경로)**
- A: 마지막 입력 토큰의 계산만 바꾼다. 앞부분은 입력당 한 번만 계산(prefill, KV cache)하고, 마지막 토큰을 조건별로 묶어 다시 계산한다.
- B (v2에서 전제가 바뀜): 개입은 마지막 이미지 뒤 토큰 26~28개의 계산만 바꾼다.
  - 그 앞 토큰들(시스템 프롬프트와 모든 이미지, 전체의 약 98%)은 뒤 토큰을 보지 않는다. 그래서 개입해도 그대로다.
  - 앞부분은 입력당 한 번만 계산하고, 뒤쪽 26~28토큰을 조건별로 묶어 다시 계산한다.
- 무개입 기준선도 같은 경로로 계산한다. 그러면 Δ에서 경로 차이가 지워진다.

**무결성 검사 (본 평가 전에 통과해야 함, 기준값 승인됨)**

| 검사 | 기준 |
| --- | --- |
| 무개입 경로 재현: 5-2b·5-2 기준 답과 margin | 파싱한 답 일치 ≥ 99%, 그리고 99% 이상의 입력에서 \|margin 차이\| ≤ 0.25. 미달이면 중단 |
| 빠른 경로 동등성: 연습 실행 일부를 전체 시퀀스 forward + 같은 개입으로 다시 계산 | 답 일치 ≥ 99%, 99% 이상의 입력에서 \|margin 차이\| ≤ 0.25 |
| A ℓ = 0 이식 | 무개입과 동일 |
| A ℓ = 36 이식 | donor의 같은 경로 margin과 0.01 이내, 답 동일 |
| B 크기 0 개입 (+log 1) | 무개입과 동일 |
| 이미지 토큰 수·구간 | 기준 실행과 같음 |

**통계**
- 97.5% N 이미지 군집 percentile 부트스트랩을 쓴다. 실험마다 주 가설이 2개라 Bonferroni 보정을 한 것이다.
- 1,000회, seed 42, 확증 절반 안에서 다시 뽑는다.
- 클래스 군집 부트스트랩으로 robust 여부를 표기한다.
- A의 C1 donor는 고정하고, 받는 쪽의 N 이미지로 다시 뽑는다.

**판정 (가설별로 따로)**

| | A-H1, A-H2 (+, 0.15) | B-H1 (+, 0.5) | B-H2 (−, 0.5) |
| --- | --- | --- | --- |
| 지지 | 추정 ≥ 0.15, CI 하한 > 0 | C ≥ 0.5, C CI 하한 > 0, **Δm(N) CI 하한 > 0** | C ≤ −0.5, C CI 상한 < 0, **Δm(N) CI 상한 < 0** |
| robust 표기 | 클래스 CI 하한 > 0 | C와 Δm(N) 모두 클래스 CI 하한 > 0 | C와 Δm(N) 모두 클래스 CI 상한 < 0 |
| 의미 있는 효과 없음 | CI 상한 < 0.15 | C CI 상한 < 0.5 | C CI 하한 > −0.5 |
| 그 외 | 결론 유보 | 결론 유보 (충족하지 못한 조건 명시) | 결론 유보 (충족하지 못한 조건 명시) |
